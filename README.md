# 项目看板

一个基于 Sites vinext starter 的项目管理看板，用于跟踪项目、任务状态、优先级、进度、阻塞和活动记录。

## 功能

- 项目、优先级和关键词筛选
- 项目增删改查、完成归档、归档总结和恢复
- 需求池、开发中、测试中、已完成四列看板
- 任务拖拽移动、列内排序、拖入回收站删除
- 任务详情抽屉，包括状态、负责人、截止日、描述、标签、阻塞项和阻塞说明
- 多子步骤 checklist，完成后联动任务进度
- 临期任务醒目标注
- 独立全局活动记录面板，记录项目、任务、子步骤和看板排序变更
- Cloudflare D1 持久化项目、任务、子步骤和活动记录

## 本地开发

```bash
pnpm install
pnpm run dev
pnpm run lint
pnpm run build
```

本地开发环境的 D1 未初始化时，`/api/board` 会返回种子数据并标记为 `storageMode: local`，页面显示“本地预览”。部署到 Sites 后，API 会通过 `.openai/hosting.json` 中声明的 `DB` 绑定读写 D1，页面显示“已保存”。

## 活动记录

活动记录是全局审计日志，不属于某个任务详情。部署后所有项目创建、项目更新、归档/恢复、任务创建、任务更新、状态变更、删除、看板排序、子步骤创建/勾选/删除都会写入 D1 的 `task_activity` 表。本地预览模式下会追加本地临时记录，用于交互验证。

## 数据库

```bash
pnpm run db:generate
```

schema 位于 `db/schema.ts`，生成的迁移文件位于 `drizzle/`。
